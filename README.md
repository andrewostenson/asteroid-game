# Asteroids Game (C# / Visual Studio)

This repo is a recreation of the classic 'Asteroid's' game using C# with several graphical, audio, and accessibility improvements.

## Features
- Player movement with physics-based momentum
- Bullet collision detection
- Asteroid splitting mechanics
- Score tracking system
- Added audio cues
- Mouse and keyboard tracking

## Technologies
- C#
- Object-Oriented Programming

## How to Run
1. Open Asteroids.sln in Visual Studio
2. Build and run in Debug or Release mode
